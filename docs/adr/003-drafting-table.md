# A shared drafting table, not an operations dashboard

Use an original warm drafting surface with movable pastel thoughts, a lined paper text editor, quiet connection/outbox receipts and a separate measured-proof sheet. The outside reference is Excalidraw's direct manipulation and separate collaboration server: https://docs.excalidraw.com/docs/introduction/development . No source, icons, graphics, fonts or layout were copied. The owned UI uses native CSS/system type, a small line mark, actual pointer events and real remote cursors.

Keep the text/canvas collaboration visible rather than simulate teammates. The offline switch actually closes transport. The proof sheet renders retained trial hashes/counts and raw propagation samples, never decorative invented telemetry. Responsive layouts and keyboard focus are checked at actual browser widths. Tokens stay in memory and visible connection state distinguishes pending local edits from committed acknowledgements.
